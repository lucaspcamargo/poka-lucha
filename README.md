## Controls

The game is controlled using the keybaord. Here are the controls for both players:

Player 1:
+ Walk Left: **A**
+ Walk Right: **D**
+ Punch: **Q**
+ Kick: **W**
+ Block: **E**

Player 2:
+ Walk Left: **J**
+ Walk Right: **L**
+ Punch: **U**
+ Kick: **I**
+ Block: **O**



## Running the game on the desktop

If you have access to a Python 3.11+ environment, the game can be run like this:

```
# navigate to project directory
$ cd poka-lucha

# create venv and activate it
$ python -m venv venv
$ source venv/bin/activate

# install dependencies
$ pip install -r ./requirements.txt

# run game
$ python -m poka_lucha
```
